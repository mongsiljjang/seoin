# 🚀 올인원 크리에이터 툴킷 (Creator All-in-One Toolkit)

유튜브 SEO 태그 · 수노(Suno) 프롬프트 · 미드저니(Midjourney) 명령어를 한 번에 만들어
**복사 / 자동입력**하는 크롬 확장프로그램입니다.

> 구글(Gemini)이 만들어준 설계도를 실제로 설치·작동 가능한 확장프로그램으로 완성한 버전입니다.

## 📦 구성 파일

```
creator-toolkit/
├── manifest.json     # 확장프로그램 설계도 (권한·아이콘·팝업 정의)
├── popup.html        # 3개 탭 UI (수노 / 미드저니 / 유튜브)
├── popup.js          # 작동 로직
├── icons/            # 아이콘 (16/32/48/128)
└── README.md
```

## 🔧 설치 방법 (개발자 모드로 직접 설치)

1. 크롬 주소창에 `chrome://extensions` 입력 후 이동
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** 클릭
4. 이 `creator-toolkit` 폴더 선택
5. 툴바에 🚀 아이콘이 생기면 클릭해서 사용

## 🎵 수노 탭
1. 음악 장르 선택 + 곡 주제 입력
2. **수노 프롬프트 복사** → 클립보드에 프롬프트 복사됨
3. [Suno](https://suno.com) 입력창에 붙여넣기

## 🎨 미드저니 탭
1. 썸네일 스타일 선택 + 피사체 입력
2. **미드저니 명령어 복사** → `/imagine prompt: ...` 형태로 복사됨
3. 디스코드 미드저니 채널에 붙여넣기

## 🎬 유튜브 탭
글로벌 SEO 태그를 미리 저장해두고, 영상마다 재사용합니다. (편집 내용은 자동 저장)

- **자동입력**: [YouTube 스튜디오](https://studio.youtube.com)의 *영상 세부정보* 페이지에서
  `자세히 보기(SHOW MORE)`를 펼쳐 **태그** 칸이 보이는 상태로 만든 뒤,
  팝업의 **스튜디오에 태그 자동입력** 버튼을 누르면 태그 칸에 채워집니다.
- **복사**: 자동입력이 잘 안 될 경우 **태그 복사** 후 태그 칸에 직접 붙여넣으세요.

> ⚠️ 유튜브 스튜디오는 화면(DOM) 구조를 자주 바꾸기 때문에 자동입력이 실패할 수 있습니다.
> 그럴 땐 **복사** 기능을 사용하면 됩니다. (복사는 항상 안정적으로 작동)

## 🔐 권한 설명
| 권한 | 용도 |
|------|------|
| `clipboardWrite` | 프롬프트·태그를 클립보드에 복사 |
| `activeTab`, `scripting` | 유튜브 스튜디오 탭에 태그 자동입력 |
| `storage` | 글로벌 태그 저장 |
| `host_permissions: studio.youtube.com` | 스튜디오 페이지에서만 스크립트 실행 |

## 🛠 구글 원본 대비 개선한 점
- ❌ **아이콘 없음** → ✅ 16/32/48/128 아이콘 추가
- ❌ **유튜브 버튼이 alert만 뜸** → ✅ 실제 스튜디오 태그 자동입력 + 복사 폴백
- ❌ **권한 부족(clipboardWrite만)** → ✅ activeTab·scripting·storage·host 권한 추가
- ❌ **inline onclick (MV3 CSP 위반)** → ✅ addEventListener 방식으로 변경
- ➕ 장르/스타일 옵션 확대, 프롬프트 미리보기, 태그 저장·재사용 기능 추가
