# Session Handoff — 2026-08-31 · Browser Use 강의 설계 (MediOps 아님)

**이 세션은 MediOps 앱 작업이 아니다.** 치과 앱 코드·규칙·배포는 아무것도 건드리지 않았다. 브랜치 `claude/browser-usage-lecture-plan-uos98m` 은 이 강의 설계 전용이다. MediOps 이어서 할 사람은 `session-handoff-2026-08-20-02.md` 부터 읽는다.

## 1. 세션 목표와 완료 결과

목표: 사용자가 의뢰받은 "브라우저 유즈" 원데이 강의(비개발자·온라인 2시간·강사 단독)의 설계.

완료: 강의 뼈대 전체 — 2시간 강의안, 심부름 공식(지시문 작성법), 부업 테마 실습 메뉴, 도입 슬라이드 6장 초안, 비유·경험담 재고, 단독 운영 수칙 — 를 `docs/LECTURE_BROWSER_USE.md` 로 확정했다. **강의 자료(슬라이드 파일·스크립트·배포 문서)는 아직 만들지 않았다** — 실측 대기 상태라서다(아래 6번).

## 2. 결정과 근거 (문서에 없는 맥락)

- **주제 확정 과정**: 사용자는 원래 "크롬 확장프로그램 만들기" 강의를 준비하다 의뢰처가 "브라우저유즈"로 바꾸라 했고, 처음엔 Browser Use 가 뭔지 몰랐다. 세션 대부분이 개념 잡기였다 — 다음 세션에서 개념 설명을 반복할 필요 없음, 사용자는 이제 이해하고 있다.
- **"실행은 강사 계정으로" 구조**: 사용자가 "유료야"라고 확인한 뒤 결정. 수강생 가입·결제·영어 사이트 장벽을 한 번에 제거하고 강사 단독 진행과 맞물린다. 이 결정은 되돌리지 않는 걸 권장 — 무료 크레딧이 넉넉해도 가입 낙오 리스크가 남는다.
- **버린 안**: ① 수강생 전원 클라우드 가입 실습(유료라 폐기) ② 설치 버전 실습(파이썬+API 키, 비개발자 불가) ③ 확장프로그램+Browser Use 2주제 실습(2시간에 불가, 주제당 60~70분 소요 계산) — 확장프로그램은 시연 5분 또는 2회차 제안으로.
- 사용자의 확장프로그램 제작 경험(수노 대량 다운로드)과 수노 20곡 크레딧 소진 사건을 강의 재료로 채택했다 — 본인 경험담이라 대체 불가.

## 6. 열린 질문 · 위험

1. **첫 실행 미완** — 사용자가 대시보드에서 지시문을 한 번도 안 돌렸다. 비용·성공률 실측 전에는 실습 문서를 확정할 수 없다.
2. **의뢰처 미확인** — 수강생 구성, 확장프로그램 시연 포함 여부. 사용자가 직접 물어야 한다.
3. **API 키 노출 위험** — 강의 화면 공유 시 대시보드의 API 키 복사 버튼 근처를 비추면 안 된다고 사용자에게 안내했다. 스크립트 쓸 때 이 경고를 포함할 것.
4. 사용자는 지금 수노에서 음악 작업 중일 수 있다(세션 말미에 이탈) — 다음 세션 시작 시 7번 실측이 됐는지부터 물어볼 것.
