# mamuri — ChatGPT 판

Claude Code 판(`../SKILL.md`)과 **같은 원리, 다른 작동 방식**이다.

> ⚠️ **이 폴더의 파일은 Claude 스킬이 아니다.** `SKILL.md` 가 없어서 Claude 의 스킬
> 업로드 창에 넣으면 "유효하지 않은 스킬" 로 거부된다. 여기 것은 ChatGPT 에
> **붙여넣고 업로드하는** 재료다. Claude 계정에 올릴 것은 저장소 루트에서
> `scripts/package.sh mamuri` 로 만드는 `dist/mamuri-skill.zip` 이다.

## 왜 그대로 못 옮기나

Claude Code 판의 심장은 2단계 **실측**이다. 에이전트가 직접 `git status` 를 돌리고
검증을 다시 실행해, 기억이 아니라 실제 상태로 핸드오프를 쓴다.

**ChatGPT 는 그걸 못 한다.** 파일도 못 열고 명령도 못 돌린다. 그 자리를 이렇게 메웠다.

| | Claude Code | ChatGPT |
|---|---|---|
| 실측 | 에이전트가 직접 돌린다 | **사용자가 붙여넣는다** |
| 안 돌렸을 때 | 스스로 알고 적는다 | **GPT 가 먼저 요청하고, 없으면 "미확인"으로 적는다** |
| 가장 큰 위험 | 실측을 건너뛰기 | **없는 걸 확인했다고 지어내기** |

그래서 지침에 절대 규칙을 박아뒀다 — **받지 않은 것을 확인했다고 쓰지 않는다.**
지어내는 것보다 "미확인"이 백 배 낫다.

## baton 판과 무엇이 다른가

`../../baton/gpt/` 에 먼저 만든 판이 있다. 뼈대는 같고 둘이 늘었다.

- **1단계에 프로젝트 관습을 캐는 표가 붙었다.** 저장소가 몇 개인지, 검증을 뭘로
  돌리는지, 문서에 내면 안 되는 게 있는지. **관습이 안 적혀 있으면 이번에 알아낸
  것을 핸드오프의 "이 프로젝트 관습" 절에 적게** 했다. 다음 세션이 같은 걸 다시
  묻지 않게 하려는 것이다
- **"사고는 반드시 적는다" 장이 생겼다.** 잘못 푸시했다거나 되돌린 화면이 있으면
  경위와 막는 법을 남긴다. 다음 세션은 그 사고를 안 겪었으므로 문서가 없으면
  똑같이 밟는다. 부끄러워서 빼면 그 대가를 다음 세션이 치른다

## 만드는 법 (커스텀 GPT)

1. ChatGPT → 왼쪽 **GPT 탐색** → **+ 만들기** → 위 탭에서 **구성(Configure)**
2. **이름**: `마무리` · **설명**: `세션을 마무리해 다음 세션에 넘긴다`
3. **지침(Instructions)**: [`INSTRUCTIONS.md`](INSTRUCTIONS.md) 통째로 붙여넣기
   (3,913자 — 한도 8,000자 안)
4. **지식(Knowledge)**: 아래 둘을 업로드
   - [`../references/PRINCIPLES.md`](../references/PRINCIPLES.md) — 규칙이 어떤 실패에서 나왔는지
   - [`../references/TEMPLATE.md`](../references/TEMPLATE.md) — 서식과 자주 나오는 실수
5. **기능**: 웹 검색·이미지 생성·코드 인터프리터 **전부 꺼도 된다.** 이 GPT 는 글만 쓴다
6. **대화 스타터**

```
오늘 작업 마무리하고 다음 세션에 넘겨줘
핸드오프 써줘. 상태는 내가 붙여줄게
이 프로젝트 규칙부터 알려줄게
지난 핸드오프 이어서 쓸래
```

## 프로젝트 기능을 쓴다면

커스텀 GPT 대신 ChatGPT **프로젝트**의 지침란에 같은 내용을 넣어도 된다.
그러면 그 프로젝트 안 모든 대화에 적용된다. 지식 파일은 프로젝트 파일로 올린다.

한 프로젝트만 쓴다면 이쪽이 편하고, 여러 작업에 두루 쓴다면 커스텀 GPT 가 낫다.

## 쓰는 법

> 오늘 작업 마무리하고 다음 세션에 넘겨줘

GPT 가 상태를 붙여달라고 요청할 것이다. [`PASTE_COMMANDS.md`](PASTE_COMMANDS.md) 의
명령을 돌려 결과를 붙여넣는다. **이 단계를 건너뛰면 핸드오프의 절반이 "미확인"으로
나온다** — 그게 정상 동작이다. 거짓말하지 않는 것이다.

## 여러 판을 같이 쓸 때

같은 프로젝트를 Claude Code · ChatGPT · Gemini 로 오가며 쓴다면
**핸드오프 문서는 한 곳에만** 둔다. 보통 저장소의 `review/` 다.
각자 자기 문서를 만들기 시작하면 다음 세션이 뭘 믿어야 할지 모른다.
