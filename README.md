# 🏥 병원 관리 앱 (재고 · 출퇴근 · 연월차)

병원에서 **재고 현황, 직원 출퇴근, 연월차**를 한 곳에서 관리하는 모바일 우선 웹앱입니다.
직원들이 카톡에서 링크만 눌러 열고, **버튼 몇 번**으로 입력할 수 있도록 마찰을 최소화했습니다.

설치가 필요 없습니다. `index.html` 파일 하나로 동작합니다.

---

## 📱 바로 사용하기

1. `index.html` 파일을 휴대폰이나 PC에서 열면 바로 실행됩니다.
2. 처음 실행하면 **예시 데이터(직원 3명, 재고 5개)** 가 들어 있어요. 설정 → *전체 데이터 초기화* 로 비울 수 있습니다.

> 💡 카톡 공유: 아래 "여러 직원이 함께 쓰려면" 방법으로 웹 주소를 만든 뒤, 그 링크를 카톡 채팅방에 올려두면 직원들이 링크만 눌러 사용할 수 있습니다.

---

## 주요 기능

| 탭 | 할 수 있는 일 |
|---|---|
| 🏠 **홈** | 오늘의 근무중 인원 · 부족 재고 · 승인대기 연월차 한눈에, 빠른 입력 |
| 📦 **재고** | 품목 등록, **엑셀/CSV 한 번에 불러오기**, **＋입고 / －출고** 원터치, 최소 보유량 이하면 자동 *부족* 표시, 검색·필터, 입출고 내역 |
| 🕒 **출퇴근** | 이름 옆 **출근/퇴근** 버튼으로 시간 자동 기록, 근무시간 계산, 이번 달 근무일·근무시간 집계 |
| 🌴 **연월차** | 연차·반차·월차·병가 신청, **승인/반려**, 직원별 잔여 연차 자동 계산 |
| 👥 **직원** | 직원 등록(부서·직급·입사일·연간 연차), 수정·삭제 |

## 📥 재고 한 번에 불러오기 (엑셀 / CSV / 사진)

재료 리스트를 하나씩 입력할 필요 없이 파일로 한 번에 등록할 수 있어요. (재고 탭 → **⬆ 엑셀**)

- **엑셀(.xlsx) / CSV 업로드**: 열은 `품목명 · 분류 · 단위 · 현재수량 · 최소보유량 · 메모`. 열 제목만 있으면 순서가 달라도 자동 인식하고, 같은 품목명은 수량이 갱신됩니다. 반영 전 미리보기(신규/수정 개수)를 보여줍니다.
- **양식 내려받기**: 불러오기 화면의 *양식 파일 내려받기(CSV)* 로 빈 양식을 받아 채워 올리면 됩니다.
- **📷 사진으로**: 손으로 적은 목록이나 기존 엑셀을 **사진으로 찍어 Claude 대화창에 보내주시면**, 바로 불러올 수 있는 파일로 만들어 드립니다. (앱 내장 사진 인식보다 정확합니다.)

> ⚙️ `.xlsx` 업로드는 `xlsx.mini.min.js` 파일이 `index.html`과 같은 폴더(또는 같은 사이트)에 있어야 동작합니다. 저장소에 함께 들어 있어요. 파일이 없으면 CSV만 지원합니다.

## 💾 데이터 저장 & 백업

- 데이터는 **이 기기의 브라우저(localStorage)** 에 저장됩니다. (서버 없음)
- 기기를 바꾸거나 백업하려면: **설정 → 백업 내보내기** 로 `.json` 파일을 저장하고, 다른 기기에서 **불러오기** 하면 됩니다.
- ⚠️ 브라우저 데이터를 지우면 함께 지워지니, 중요한 데이터는 주기적으로 백업하세요.

## 👥 여러 직원이 함께 쓰기 (공유 버전) — 지원됨 ✅

카톡에 올린 **링크 하나로 전 직원이 같은 데이터를 실시간 공유**할 수 있습니다.
직원들은 설치·가입 없이 링크만 누르면 되고, 상단 배지가 **☁︎ 공유중** 이면 연결된 상태예요.

- 켜는 방법: **[`SETUP-공유버전.md`](SETUP-공유버전.md)** 를 따라 Firebase(무료)를 만들고 `firebase-config.js`에 설정값을 넣은 뒤, 앱을 호스팅해 링크를 공유하면 됩니다.
- `firebase-config.js`가 **비어 있으면** 앱은 기존처럼 **'이 기기 저장'** 모드로 동작합니다. (설정 전까지 그대로 사용 가능)
- 동기화 방식: 변경 시 전체 데이터를 실시간 반영(last-write-wins). 소규모 병원 사용에 맞춘 MVP 방식입니다.

> 📷 사진을 찍으면 AI가 재고를 자동 입력하는 기능은 다음 단계로 추가할 수 있습니다 (Firebase 서버 위에 얹음).

## 🛠 기술

- 순수 HTML/CSS/JavaScript 단일 파일 (프레임워크·빌드 도구 없음)
- 오프라인에서도 동작, 카카오톡 인앱 브라우저 호환
- 데이터: `localStorage` (JSON 백업/복원 지원)
