# 🤖 네이버 글쓰기 에이전트 (빠글AI식 자동화 — 내 프롬프트 버전)

키워드 목록만 적어두면, 제미나이 API로 글 초안을 뭉치로 생성하고 워드프레스에 자동 업로드까지 하는 **강사님 전용** 자동화입니다.
빠글AI 같은 서비스와 파이프라인은 같지만, 프롬프트가 내 것(의료광고법·보험업법 가드레일 + 휴머나이징 규칙)이고, 비용은 월 구독이 아니라 **글 한 편에 몇십 원**입니다.

> ⚠️ **이 폴더는 배포하면 안 됩니다.** `설정.json`에 내 API 키가 들어가기 때문입니다.
> 배포용은 클립보드 방식(`../index.html`, `../크롬확장/`)만 쓰세요.

## 처음 한 번만 하는 준비 (10분)

1. **Node.js 설치** — https://nodejs.org 에서 LTS 버전 내려받아 설치 (다음-다음-다음이면 됩니다)
2. **제미나이 API 키 발급** — https://aistudio.google.com/apikey 에 구글 계정으로 로그인 → **[API 키 만들기]** → 복사
   - 제미나이 앱 유료 구독과는 **별개**입니다. API는 쓴 만큼 과금(글 한 편 몇십 원 수준)이며 결제 수단 등록이 필요할 수 있습니다.
3. `설정.json`을 메모장으로 열어 `"제미나이키": ""` 따옴표 사이에 붙여넣기

## 매번 쓰는 법 (2분)

1. `키워드.txt`를 메모장으로 열고 한 줄에 하나씩 적습니다:
   ```
   키워드 | 프리셋 | 경험 한 줄 | 톤
   ```
   - **프리셋**(선택): `병원` `브랜딩` `보험` `범용` — 비우면 설정의 기본프리셋
   - **경험**(선택): 비우면 글에 `[여기에 본인 경험 한 줄]` 자리가 남습니다 (지어내지 않음)
   - **톤**(선택): `감성` `전문가` `GEO` — 넣으면 초안을 한 번 더 변환합니다 (호출 2배 = 비용 2배)
2. 이 폴더에서 명령창(터미널)을 열고:
   ```
   node agent.mjs
   ```
3. 결과는 `초안/` 폴더에 날짜_키워드.md 파일로 쌓입니다.

## 워드프레스 자동 업로드 (선택)

1. 내 워드프레스 관리자 → 사용자 → 프로필 → **응용 프로그램 비밀번호** 새로 만들기 → 복사
2. `설정.json`의 워드프레스 부분을 채우고 `"사용": true`로:
   ```json
   "워드프레스": {
     "사용": true,
     "주소": "https://내사이트주소.com",
     "아이디": "관리자아이디",
     "응용프로그램비밀번호": "xxxx xxxx xxxx xxxx",
     "발행상태": "임시글"
   }
   ```
3. 다시 실행하면 글이 **임시글(draft)**로 올라갑니다. 관리자 화면에서 검토 → 발행 버튼만 누르면 끝.
   - `"발행상태": "즉시발행"`으로 바꾸면 검토 없이 바로 공개됩니다. **의료·보험 글은 임시글을 권장합니다** (발행 전 법 검수는 사람 몫).

## 설정.json 항목

| 항목 | 뜻 | 기본값 |
|---|---|---|
| 제미나이키 | API 키 | (비움 — 필수) |
| 모델 | 사용할 제미나이 모델 | gemini-2.5-flash |
| 기본프리셋 | 키워드 줄에 프리셋을 안 적었을 때 | 병원 |
| 기본톤 | 키워드 줄에 톤을 안 적었을 때 (`없음`이면 변환 생략) | 없음 |
| 글사이대기초 | 글과 글 사이 쉬는 시간(초) — 사용량 제한 예방 | 3 |

## 발행 전 사람이 하는 3가지 (자동화 금지 구역)

1. `[여기에 본인 경험 한 줄]` → 진짜 경험으로 채우기
2. `[확인 필요]` → 수치·사실 확인
3. `(사진: …)` → 직접 찍은 사진 넣기

## 자주 나는 문제

- **"제미나이 API 키가 비어 있습니다"** — 설정.json에 키를 안 넣은 것. 위 준비 2~3번.
- **429 / 사용량 제한** — 에이전트가 알아서 쉬었다 다시 시도합니다. 계속 나면 글사이대기초를 10으로.
- **워드프레스 401/403** — 아이디나 응용 프로그램 비밀번호가 틀린 것. 로그인 비밀번호가 아니라 **응용 프로그램 비밀번호**여야 합니다.
- **글이 마음에 안 듦** — agent.mjs 안의 프리셋 문구를 직접 고치면 됩니다 (../index.html, ../크롬확장/popup.js 와 같은 내용이니 같이 고치기).
