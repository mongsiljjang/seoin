# 🖊️ 네이버 글쓰기 도우미

대표키워드 하나로 시작해서, 네이버 상위노출 규칙과 **법적 금지 표현(의료광고법·보험업법)**까지 지킨 글 한 편을 제미나이·챗GPT로 뽑아내는 도구입니다.

**같은 도구가 두 가지 모습으로 있습니다 (이중 트랙):**

| 트랙 | 파일 | 누구에게 |
|---|---|---|
| **웹페이지 한 장** | `index.html` | 미끼상품 배포·판매용. 링크나 파일만 열면 바로 작동, 설치 제로 |
| **크롬 확장** | `크롬확장/` 폴더 | 강의 실습용. "내 브라우저에 내 툴을 설치했다"는 성취감이 목적 |
| **에이전트** | `에이전트/` 폴더 | **내 업무 전용, 배포 금지.** 키워드 목록→초안 뭉치 자동 생성→워드프레스 임시글 업로드 (제미나이 API 키 필요) |

두 트랙의 글쓰기 로직(프리셋·명령서·톤 변환)은 동일합니다. **한쪽을 수정하면 반드시 다른 쪽도 같이 수정하세요.**

---

## 이 도구가 하는 일 / 하지 않는 일

**하는 일** — 검증된 글쓰기 명령서를 자동으로 조립해서 클립보드에 복사해 줍니다. 사용자는 쓰던 AI(제미나이·챗GPT·클로드 어디든)에 붙여넣고 엔터만 치면 됩니다. API 키·가입·결제가 전혀 없어서 무료이고 에러 날 곳이 없습니다.

**하지 않는 일** — 도구가 스스로 글을 생성하지 않습니다. 실제 작성은 사용자가 쓰던 AI 창에서 이뤄집니다. (도구 안에서 글까지 나오게 하려면 유료 API 연동이 필요한데, 배포용 도구에 API 키를 심으면 키가 노출되어 비용 폭탄을 맞습니다. 클립보드 방식이 이 사업 모델에서는 정답입니다.)

**어느 AI를 쓰든 됩니다** — 클립보드 방식이라 특정 AI에 묶이지 않습니다. 제미나이·챗GPT 유료 구독이 있다면 그 구독을 그대로 활용하면 됩니다(구독은 API 키가 아니라서 도구에 연동할 수는 없지만, 붙여넣기에는 아무 제약이 없습니다). 유료 모델일수록 긴 명령서를 잘 따르고 결과 품질이 좋습니다.

---

## 사용 흐름 (3단계)

### 1단계 · 글 명령서 만들기
1. **글의 주제**를 고릅니다. 주제마다 다른 규칙이 명령서에 자동으로 들어갑니다.
   - **병원 블로그** — ⚖️ 의료광고법 가드레일: "완치·100%·부작용 없음" 등 단정 표현 금지, 환자 치료경험담·전후사진 금지, 타병원 비교 금지, 가격 이벤트 금지, "정확한 진단은 의료진 상담 필요" 명시
   - **전문가 브랜딩** — 병원 현장 경력을 근거로 쓰는 내 이름 블로그. 특정 병원 홍보 금지, 환자 특정 정보 금지
   - **기업보험·경영** — 주제는 유연하게(위험관리·직원 복지·정부 지원·노무 상식 등)를 "사업주의 위험을 줄인다"는 관점으로 폭넓게 다루고, 글이 보험을 다룰 때만 ⚖️ 보험업법 가드레일 적용: "무조건 보장·전액 지급" 금지, 타사 비방 금지, 미확정 수치 금지, 약관 확인 안내 문구 필수
   - **범용** — 어떤 주제든. 실습 교재용으로도 사용
   - **＋ 내 업종 추가** — 업종 이름과 규칙을 직접 등록하면 프리셋으로 저장됩니다
2. 대표키워드와 (선택) 내 경험 한 줄을 넣고 **[글 명령서 복사]** → 제미나이·챗GPT에 붙여넣기 → 엔터.
3. 제목 후보 5개(3개는 세부 키워드 조합)와 본문 초안이 나옵니다.

명령서에 항상 들어가는 네이버 규칙: 인사말 없는 경험+두괄식 첫 문단 · 질문형 소제목 바로 아래 정답 · 표/불릿 1개 이상 · 대표키워드 3번 안팎(유의어 대체) · 사진 자리 3곳 표시 · FAQ와 해시태그 · 불확실한 수치는 `[확인 필요]`.

### 2단계 · 사람의 언어로 다듬기
초안을 붙여넣고 톤 버튼을 누르면 변환 명령이 글에 붙어 복사됩니다.

- **감성 블로그 톤** — 1인칭 시작, AI식 형용사 삭제, 문장 비대칭, 접속사 80% 감소
- **전문가 칼럼 톤** — 감성 배제, 근거·수치, 두괄식
- **GEO·AEO 구조화** — 질문형 소제목+정답, 유의어, 불릿·표

세 버튼 모두 **원본의 사실·수치·법적 안내 문구는 지우지 말 것**이라는 규칙이 함께 들어갑니다. (톤을 바꾸다 가드레일 문구가 사라지는 사고 방지)

### 3단계 · 발행 전 직접 할 일 (도구가 못 하는 것)
1. `[여기에 본인 경험 한 줄]`을 진짜 경험으로 채우기 — 네이버 D.I.A.+는 직접 경험에 가산점
2. `[확인 필요]` 수치·사실 확인
3. `(사진: …)` 자리에 직접 찍은 사진 — 퍼온 이미지는 유사이미지 검사에 걸림

> 경험 칸을 비우면 경험을 **지어내지 않고** 자리를 남기게 설계되어 있습니다. 의료·보험 글에서 지어낸 경험은 법적 문제가 되기 때문입니다.

## 배포 방법

**웹페이지 트랙**: `index.html` 파일 하나를 그대로 전달하거나(카톡·메일), GitHub Pages 등에 올려 링크로 공유합니다. 입력 내용은 각자의 브라우저에만 저장됩니다.

**크롬 확장 트랙 (강의 실습)**:
1. `크롬확장` 폴더의 파일 3개를 수강생이 직접 저장 (메모장 저장 시 파일 형식 **모든 파일(\*.\*)**, 인코딩 **UTF-8**)
2. 크롬 주소창 `chrome://extensions` → **[개발자 모드]** 켜기
3. **[압축해제된 확장 프로그램을 로드합니다]** → 폴더 선택

## 실습 중 에러가 나면 (AI 디버깅 훈련)

빨간 에러 텍스트를 복사해 쓰던 AI(제미나이·챗GPT)에 이렇게 묶어 붙여넣게 하세요.

```
[내가 띄우려던 전체 코드]
(파일 내용)

[발생한 에러 메시지]
(빨간 글씨)

뭐가 문제인지 찾아서 수정된 전체 코드로 다시 출력해 줘.
```

자주 나는 에러: "Manifest file is missing or unreadable"(폴더가 아닌 파일 선택, 또는 `.txt`로 저장됨) · 한글 깨짐(UTF-8 아님) · 버튼 무반응(`popup.js` 파일명이 다르거나 없음).

## 기술 메모

- 크롬 확장 팝업에서는 `prompt()`·`confirm()`·인라인 `<script>`가 작동하지 않습니다 → 입력 폼 + 외부 `popup.js`로 구현.
- 팝업/페이지를 닫아도 키워드·경험·초안·프리셋이 저장됩니다 (확장: `chrome.storage`, 웹: `localStorage`).
- 관련 제품: 자주 쓰는 GPT 링크 저장은 별도 도구 **GPT 핀셋**(`../크롬확장-GPT핀셋/`)으로 분리되어 있습니다.
