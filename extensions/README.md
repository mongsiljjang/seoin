# 크롬 확장 프로그램 모음

두 개의 크롬 확장 프로그램이 들어 있습니다. 둘 다 **크롬(또는 엣지 등 크로미움 브라우저)** 에서 동작합니다.

| 폴더 | 확장 이름 | 용도 |
|---|---|---|
| [`hospital/`](hospital) | 병원 관리 앱 런처 | 기존 병원 관리 앱(재고·출퇴근·연월차)을 툴바 아이콘/단축키로 바로 열기 |
| [`suno-toolbox/`](suno-toolbox) | 내 도구함 – 수노 일괄 다운로드 · 메모 | 메모/할일·페이지 저장 + Suno 곡 골라서 한 번에 WAV 저장 |

---

## 설치 방법 (공통)

개발자 모드로 직접 불러오면 됩니다. (크롬 웹스토어 등록 없이 바로 사용 가능)

1. 크롬 주소창에 `chrome://extensions` 입력 → 이동
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 원하는 폴더 선택
   - 병원 런처 → `extensions/hospital` 폴더
   - 개인 도구함 → `extensions/suno-toolbox` 폴더
5. 툴바의 퍼즐(🧩) 아이콘에서 각 확장을 **고정(핀)** 해두면 편합니다.

> 코드를 수정한 뒤에는 `chrome://extensions` 에서 해당 확장의 **↻ 새로고침** 을 눌러 다시 로드하세요.

---

## 1) 병원 관리 앱 런처 (`hospital/`)

병원 관리 앱은 원래 **웹앱(PWA)** 으로 만들어져 있어, 크롬 확장 안에 그대로 넣으면
크롬 보안정책(MV3) 때문에 버튼이 동작하지 않습니다. 그래서 이 확장은 앱을 **여는 런처**
역할을 합니다.

**쓰는 법**
1. 툴바 아이콘 클릭 → **설정** 에 앱 주소(URL)를 넣고 저장
   - 앱을 웹에 올려둔 주소를 넣습니다. (예: GitHub Pages, Firebase 호스팅 등)
   - 저장소 루트의 [`SETUP-공유버전.md`](../SETUP-공유버전.md) 를 따르면 무료로 호스팅 + 공유까지 됩니다.
2. 이후에는 아이콘 클릭 → **앱 열기**, 또는 단축키 **Ctrl/⌘ + Shift + H** 로 바로 실행
3. “앱 창으로 열기”를 켜면 주소창 없는 앱 전용 창으로 뜹니다.

## 2) 내 도구함 (`suno-toolbox/`)

한 확장에 세 가지 기능이 들어 있습니다. 툴바 아이콘을 누르면 팝업에 탭으로 나옵니다.

- **📝 메모** — 자유 메모, 자동 저장
- **✅ 할일** — 체크리스트
- **🔖 페이지** — 지금 보는 웹페이지 주소를 한 번에 저장/열기

### 🎵 Suno 곡 일괄 WAV 저장 (핵심 기능)

Suno에서 **한 곡씩** 받는 대신, 여러 곡을 골라 **한 번에 WAV 파일**로 저장합니다.

1. `suno.com` 에서 내 라이브러리/플레이리스트를 엽니다.
2. 곡들이 화면에 보이도록 스크롤합니다.
3. 화면 오른쪽 아래 **⬇ 곡 저장** 버튼을 누릅니다.
4. 원하는 곡을 체크하고(전체 선택도 가능) **선택 곡 WAV로 저장** 을 누릅니다.
5. 다운로드 폴더의 **`Suno/`** 폴더에 WAV로 저장됩니다.

**동작 방식** — 브라우저가 이미 재생용으로 접근하는 오디오를 받아, 확장 내부에서
디코딩 후 16-bit PCM WAV 로 변환해 저장합니다. 한 번에 받는 곡 수 제한은 없습니다.

> ⚠️ **주의**: 본인이 만든 곡을 개인적으로 보관·백업하는 용도로만 사용하세요.
> Suno의 이용약관과 저작권을 지키는 것은 사용자 책임입니다.

**곡이 안 잡힐 때**
- 라이브러리 페이지에서 곡이 실제로 화면에 보이도록 스크롤한 뒤 패널의 **↻(다시 스캔)** 을 누르세요.
- Suno가 페이지 구조를 바꾸면 오디오 주소를 못 찾을 수 있습니다. 이 경우
  `content/suno.js` 의 셀렉터를 최신 구조에 맞게 갱신해야 합니다.
- 오디오가 `*.suno.ai` 가 아닌 다른 CDN에서 제공되면, `manifest.json` 의
  `host_permissions` 에 해당 도메인을 추가해야 합니다.

---

## 기술 메모

- 둘 다 **Manifest V3** 확장입니다.
- 도구함의 WAV 변환은 **오프스크린 문서(offscreen document)** 에서 Web Audio 로
  디코딩 → WAV 인코딩하며, 저장은 백그라운드 서비스워커의 `chrome.downloads` 로 처리합니다.
- 저장 데이터(메모·할일·페이지·런처 설정)는 `chrome.storage.local` 에 보관됩니다.
