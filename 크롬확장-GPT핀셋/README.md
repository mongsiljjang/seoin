# 🎨 나만의 무한대 GPT 핀셋 (강의 실습용 크롬 확장 프로그램)

챗GPT 고정핀 10개 제한을 해결하는 **무한대 컬러 팝업** + 챗GPT가 쓴 글을 사람의 언어로 바꿔주는 **원클릭 변환 복사기**.
파일 3개(`manifest.json`, `popup.html`, `popup.js`)만으로 작동합니다. 설치 프로그램도, API 키도, 결제도 없습니다.

> 출처: 구글 문서 「구글 앱스 스크립트 주요 활용 용도」(Gemini 대화 기획안)를 실제 작동 코드로 옮긴 것.

## 🚀 1분 만에 크롬에 띄우는 방법

1. **폴더 준비** — 이 폴더(`크롬확장-GPT핀셋`)를 통째로 내 컴퓨터에 내려받습니다. (수강생 실습이라면: 바탕화면에 `GPT핀셋` 폴더를 만들고 파일 3개를 복사해 저장합니다. 메모장 저장 시 파일 형식을 **모든 파일(\*.\*)**, 인코딩을 **UTF-8**로 바꿔야 합니다.)
2. **개발자 모드 켜기** — 크롬 주소창에 `chrome://extensions` 를 치고 엔터. 우측 상단 **[개발자 모드]** 를 켭니다.
3. **로드** — 좌측 상단 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 누르고 폴더를 통째로 선택합니다. 끝.

## 사용법

### 고정핀 (개수 무제한)
- 컬러 버튼을 누르면 저장해 둔 GPT 링크가 새 탭으로 열립니다.
- **＋ 새로운 프롬프트 핀 추가** → 이름과 링크를 넣고 저장. 파스텔 색은 자동으로 입혀집니다.
- 핀 오른쪽 위 **✕** 를 두 번 누르면 삭제됩니다. (실수 방지용 2단계)

### 변환 복사기 (클립보드 결합 방식)
1. 챗GPT가 써준 밋밋한 글을 복사해서 아래 큰 칸에 붙여넣습니다.
2. 톤 버튼 하나를 누릅니다.
   - **감성 블로그 톤** — 1인칭 경험으로 시작, AI식 형용사 삭제, 문장 길이 비대칭, 접속사 80% 감소
   - **전문가 칼럼 톤** — 감성 배제, 통계·수치, 두괄식 단호한 어조
   - **GEO·AEO 구조화** — 질문형 소제목 + 두괄식 정답, 유의어 그물망, 불릿·표 마크다운
3. "복사 완료!" 알림이 뜨면, 쓰던 챗GPT 창에 **붙여넣기(Ctrl+V) → 엔터**. 글 밑에 숨겨진 변환 명령이 함께 들어가 챗GPT가 스스로 고쳐 씁니다.

> 툴은 80% 초벌 엔진입니다. 글의 **첫 문장과 마지막 문단**은 반드시 본인의 진짜 경험으로 직접 고쳐 쓰세요.

## 원본 기획안 코드와 달라진 점 (실제 작동을 위한 수정)

## 실습 중 에러가 나면 (AI 디버깅 훈련)

에러 화면은 고장이 아니라 커리큘럼입니다. 빨간 에러 텍스트를 드래그해 복사한 뒤, 챗GPT에 아래처럼 묶어서 붙여넣게 하세요.

```
[내가 띄우려던 전체 코드]
(파일 내용 붙여넣기)

[발생한 에러 메시지]
(빨간 글씨 붙여넣기)

뭐가 문제인지 찾아서 수정된 전체 코드로 다시 출력해 줘.
```

자주 나는 에러 두 가지:
- **"Manifest file is missing or unreadable"** — 폴더가 아니라 파일을 선택했거나, 파일명이 `manifest.json.txt` 로 저장된 경우. 파일 형식을 *모든 파일*로 바꿔 다시 저장.
- **한글이 깨져 보임** — 메모장 저장 시 인코딩을 **UTF-8**로 선택.
