# 🎨 나만의 무한대 GPT 핀셋 (강의 실습용 크롬 확장 프로그램)

챗GPT 고정핀 10개 제한을 해결하는 **무한대 컬러 팝업**입니다.
자주 쓰는 GPT·사이트 링크를 파스텔 버튼으로 개수 제한 없이 저장하고, 버튼 한 번으로 새 탭에서 엽니다.
파일 3개(`manifest.json`, `popup.html`, `popup.js`)만으로 작동합니다. 설치 프로그램도, API 키도, 결제도 없습니다.

> 이 도구는 **핀(바로가기) 전용**입니다. 네이버 블로그 글쓰기(키워드 명령서·톤 변환)는 별도 제품인
> **네이버 글쓰기 도우미**(`../네이버-글쓰기-도우미/`)로 분리되어 있습니다.

## 🚀 1분 만에 크롬에 띄우는 방법

1. **폴더 준비** — 이 폴더를 통째로 내 컴퓨터에 내려받습니다. (수강생 실습이라면: 바탕화면에 `GPT핀셋` 폴더를 만들고 파일 3개를 메모장으로 저장. 저장 시 파일 형식을 **모든 파일(\*.\*)**, 인코딩을 **UTF-8**로.)
2. **개발자 모드 켜기** — 크롬 주소창에 `chrome://extensions` 입력 → 우측 상단 **[개발자 모드]** 켜기.
3. **로드** — 좌측 상단 **[압축해제된 확장 프로그램을 로드합니다]** → 폴더를 통째로 선택. 끝.

## 사용법

- 컬러 버튼을 누르면 저장해 둔 링크가 새 탭으로 열립니다.
- **＋ 새로운 프롬프트 핀 추가** → 이름과 링크를 넣고 저장. 파스텔 색은 자동으로 입혀집니다.
- 핀 오른쪽 위 **✕** 를 두 번 누르면 삭제됩니다. (실수 방지용 2단계)

## 원본 기획안 코드와 달라진 점 (실제 작동을 위한 수정)

| 기획안 | 이 코드 | 이유 |
|---|---|---|
| 핀 추가에 `prompt()` 사용 | 팝업 안 입력 폼 | 크롬 확장 팝업에서는 `prompt()`·`confirm()` 창이 뜨지 않아 버튼이 먹통이 됨 |
| 핀 삭제 없음 | ✕ 두 번 눌러 삭제 | "무한 추가"만 있으면 잘못 만든 핀을 지울 방법이 없음 |

## 실습 중 에러가 나면 (AI 디버깅 훈련)

에러 화면은 고장이 아니라 커리큘럼입니다. 빨간 에러 텍스트를 드래그해 복사한 뒤, 챗GPT에 아래처럼 묶어서 붙여넣게 하세요.

```
[내가 띄우려던 전체 코드]
(파일 내용 붙여넣기)

[발생한 에러 메시지]
(빨간 글씨 붙여넣기)

뭐가 문제인지 찾아서 수정된 전체 코드로 다시 출력해 줘.
```

자주 나는 에러 두 가지:
- **"Manifest file is missing or unreadable"** — 폴더가 아니라 파일을 선택했거나, 파일명이 `manifest.json.txt` 로 저장된 경우. 파일 형식을 *모든 파일*로 바꿔 다시 저장.
- **한글이 깨져 보임** — 메모장 저장 시 인코딩을 **UTF-8**로 선택.
