# MediOps 사용 안내 — 최지원 님께

치과 재고·임플란트·출퇴근·연월차를 한 곳에서 보는 앱입니다.
폰과 컴퓨터 어디서나 같은 주소로 열립니다.

## 1. 접속

- 주소: **https://mediops-pilot.vercel.app/**
- 폰: 브라우저(크롬·사파리)로 열고 `홈 화면에 추가`를 해 두면 앱처럼 열립니다.
- 처음 열어 보기만 하려면 주소 끝에 `?demo=1`을 붙입니다 (`https://mediops-pilot.vercel.app/?demo=1`).
  가짜 자료로 둘러보는 화면이라 로그인이 없고, 입력한 것은 저장되지 않습니다.
- 지금은 시험 단계라 앱 안의 자료는 모두 연습용입니다. 마음껏 눌러 보셔도 됩니다.

## 2. 이번에 새로 생긴 것 — 빠진 입력 확인

**임플란트 탭** 맨 위, 재고 숫자 아래에 `📝 빠진 입력 확인` 상자가 있습니다.
장부와 입력이 어긋난 곳을 할 일 목록으로 알려 줍니다. 판정이나 기록 평가가 아니고, 홈 화면에는 나오지 않습니다.

| 상자에 뜨는 말 | 뜻 | 하면 되는 일 |
|---|---|---|
| 쓴 N개가 들어온 M개보다 많아요 | 쓴 개수는 적혔는데 들어온 기록이 모자람 | 입고를 빠뜨렸으면 `＋ 입고`로 넣기, 앱 쓰기 전부터 있던 물건이면 이월재고로 넣기 |
| 남은 재고를 센 지 30일 넘은 규격 | 마지막으로 센 지 한 달 넘음 | 규격을 눌러 `📋 남은 재고 입력` |
| 남은 재고를 한 번도 안 센 규격 | 센 적이 없음 | 위와 같음 |
| 케이스에 적었는데 재고 목록에 없는 규격 | 케이스에 쓴 규격이 재고에 없어서 재고가 안 줄어듦 | 재고에 그 규격 추가, 또는 케이스의 규격 글자 고치기 |
| 고정체·힐링·지대주가 모두 빈 치아 줄 | 치아 번호만 있고 쓴 재료가 없음 | 임플란트 대장에서 그 케이스를 열어 채우기 |

문제가 없으면 `✓ 빠진 입력이 보이지 않아요`라고 나옵니다.

## 3. 자주 쓰는 순서

1. **임플란트 탭** → 회사를 누르면 부품·제품이 펼쳐지고, 제품을 누르면 규격 표가 나옵니다. `선택`이 기본이고 규격 표만 보입니다.
2. 물건이 들어오면 규격을 눌러 `＋ 입고`, 쓰면 `－ 사용` (일반·보험·페일 중 구분).
3. 수술 기록은 **임플란트 대장 → ＋ 케이스**에 넣으면 쓴 재료만큼 재고에서 자동으로 빠집니다. 수첩 내용은 `📝 수첩`으로 한꺼번에 옮길 수 있습니다.
4. 월말에 선반의 실제 개수를 세어 `📋 남은 재고 입력`에 넣으면 장부와 비교됩니다.

## 4. 사진 대신 글로 옮기기 (지금은 이쪽을 쓰세요)

`사진으로 올리기`는 AI 키를 넣기 전까지 꺼져 있습니다. 그래서 지금은 **수첩 → ✍️ 글로 붙여넣기**를 씁니다.
이미 찍어 둔 수첩 사진이 있으면, 폰이 사진에서 글자를 뽑아 주는 기능으로 글을 복사해 붙이면 됩니다. 사진을 앱에 올리지 않고 폰 안에서만 처리됩니다.

**아이폰**
1. 사진 앱에서 수첩 사진을 엽니다.
2. 글자 부분을 길게 누르면 글자가 선택됩니다. 선택이 안 되면 사진 오른쪽 아래의 글자 모양 아이콘을 누르세요.
3. `복사`를 누릅니다.
4. MediOps → 임플란트 대장 → `📝 수첩` → `✍️ 글로 붙여넣기` 칸에 붙여넣습니다.

**안드로이드**
1. 갤러리(또는 구글 포토) 앱에서 수첩 사진을 엽니다.
2. 아래의 `렌즈` 아이콘을 누르고 `텍스트`를 고릅니다. 갤러리에 렌즈가 없으면 Google 렌즈 앱에서 `사진 불러오기`로 엽니다.
3. 글자가 선택되면 `모두 복사`를 누릅니다.
4. MediOps → 임플란트 대장 → `📝 수첩` → `✍️ 글로 붙여넣기` 칸에 붙여넣습니다.

**카카오톡에 올린 글·사진을 쓰려면**
- 카톡 대화에 **글**로 적어 둔 것이면 말풍선을 길게 눌러 `복사`한 뒤 붙여넣으면 됩니다. 가장 쉽고 정확합니다.
- 카톡에 올린 것이 **사진**이면 카톡에서 바로 글자를 뽑는 기능이 기종·버전마다 달라서 장담하지 못합니다. 사진을 폰에 저장한 뒤 위의 아이폰·안드로이드 방법을 쓰세요.
- PC에서 작업할 때는 폰에서 복사한 글을 카톡 `나에게 보내기`로 보내고, PC 카톡에서 복사해 붙이면 됩니다.

**한 줄에 꼭 들어가야 하는 것 (수첩 붙여넣기)**

한 줄에 환자 한 명의 한 번 수술을 적습니다. 예: `박소영 보험 #46 오스템 4.0*12`

| 항목 | 필수? | 쓰는 법 | 빠지면 |
|---|---|---|---|
| 치아 번호 | **꼭** | `#46` 처럼 # 뒤에 두 자리. 여러 개는 `#46,47` 또는 `#46#47` | "치아번호가 없어요"라며 저장이 안 됩니다 |
| 규격 | **꼭** (1차 수술) | `4.0*12` 처럼 지름*길이 (`×`도 됨) | "규격을 못 읽었어요"로 저장이 안 됩니다 |
| 이름 | 사실상 필수 | 성과 끝 글자가 남고 가운데는 초성으로 가려져 저장됩니다. 윗줄과 같은 환자면 비워도 됩니다 | 이름도 차트번호도 없는 케이스가 만들어집니다. 2차 수술은 이름이 같아야 1차에 붙습니다 |
| 회사(브랜드) | 권장 | 규격 바로 앞에 `오스템`, `덴티움` 등 | 같은 규격이 여러 회사에 있으면 엉뚱한 제품으로 잡힐 수 있습니다 |
| 보험 / 일반 | 보험이면 꼭 | 보험이면 `보험`을 적고, 안 적으면 **일반**으로 처리됩니다 | 보험 케이스가 일반으로 들어갑니다 |
| 페일 | 해당될 때 | `페일` 또는 `실패` | 사용이 일반으로 세어집니다 |
| 날짜 | 선택 | `8/21`, `8-21`, `2026-08-21` | 오늘 날짜로 들어갑니다 (표에서 고칠 수 있어요) |
| 2차 수술 | 해당될 때 | 줄에 `2차`를 쓰고 이름·치아 번호·힐링을 적습니다. 예: `박소영 2차 #46 GH3` | 1차 기록을 못 찾으면 붙지 않으니 이름과 치아 번호를 1차와 똑같이 맞추세요 |

- 규격과 회사는 앱의 **재료 목록에 있는 것**이어야 재고에서 빠집니다. 목록에 없으면 "재료 목록에 없는 규격이에요"라고 나오니 먼저 재고에 그 규격을 추가하세요.
- 날짜에 마침표(8.21)는 쓰지 마세요. 규격 4.0과 헷갈려 날짜로 읽지 않습니다.
- 환자 전화번호·주민번호는 붙여넣지 마세요. 카톡 글에 섞여 있으면 지우고 붙여넣습니다.

**붙여넣은 뒤**
- 앱이 줄을 읽어 확인 표로 보여 줍니다. 손글씨는 잘못 읽히는 곳이 있으니 규격과 개수를 눈으로 확인하고, 틀린 곳은 표에서 고친 뒤 반영하세요.
- 환자 이름은 쓰지 마시고, 이름이 적혀 있으면 앱이 가운데 글자를 가려 저장합니다.
- 글자 선택이 잘 안 되면 사진이 흐리거나 기울어서입니다. 그럴 때는 수첩 내용을 직접 타자로 붙여넣거나 `＋ 케이스`에 하나씩 넣으세요.

**LOT 번호 (📷 버튼)**
- LOT 칸 옆 `📷`도 지금은 쓰지 않고 **칸에 직접 적습니다.** 박스 라벨의 LOT 글자를 위 방법으로 복사해 붙여도 됩니다.

## 5. 환자 정보 입력 규칙

- 차트번호 **또는** 이름 하나만 있으면 됩니다. 전화번호·주민번호는 넣지 않습니다.
- 이름을 입력하면 앱이 가운데 글자를 가려 저장합니다 (김민수 → 김ㅁ수). 원본 이름은 저장되지 않습니다.

## 6. 불편한 곳이 있으면

어느 화면에서 무엇을 눌렀더니 어떻게 되었는지 한 줄이면 충분합니다. 폰 기종과 브라우저를 같이 알려 주시면 더 빨리 고칠 수 있습니다.
