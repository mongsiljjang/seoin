# 파일럿 테스트 플랜

## 인증/권한
- 미등록 번호 로그인 차단
- inactive 로그인 차단
- employee의 관리자 API 접근 차단
- 병원 A 사용자의 병원 B 데이터 접근 차단
- admin의 super_admin 임의부여 차단

## 근태
- 정상 QR+GPS 출근/퇴근
- 잘못된 QR
- GPS 범위 밖
- 위치권한 거부
- 중복 출근
- 출근 없이 퇴근
- 미퇴근 감지
- 병원 밖 수정요청만 가능
- 지각유예 0/5/10분
- 조퇴/연장근무 계산
- 근무변경 승인 후 기준시간 변경
- 반차 승인 후 지각 오판정 없는지

## 연차
- 연차/오전반차/오후반차
- 승인/반려
- 잔여차감
- 연차 부족 신청 처리정책
- 퇴사/입사일 경계

## 재고
- -1/-5 차감
- 최소재고 도달 알림
- 입고
- 재고조정
- 조정 전/후 감사로그
- CSV 업로드 오류행

## LOT/유통기한
- 동일품목 다중 LOT
- 임박순 정렬
- FEFO 안내
- 만료 LOT 사용 제한 정책 검토

## 발주
- 발주 필요→주문→입고대기→입고완료
- 입고 시 LOT/재고 증가
- 과거 구매단가 보존

## 패키지
- 복수 패키지
- 적용품목 제한
- 금액 차감
- 서비스 수량 차감
- D-day 알림
- 재계약 잔액합산
- 서비스 이월
- 패키지 연결품목만 교환
- 1:N 교환
- 교환 취소 역거래
- 기존 계약원장 보존

## 파일럿 KPI
도입 전 2~4주 기준치를 확보하고 도입 후 동일 기간 비교 권장.
