## 0. 확정된 조건

| 항목 | 내용 |
|---|---|
| 주제 | Browser Use (browser-use, cloud.browser-use.com) — AI 브라우저 자동화 |
| 대상 | 비개발자 (부업 관심층 가능성 높음 — 의뢰처 확인 필요) |

| 학습 목표 | ① AI 브라우저 자동화로 되는 일/안 되는 일 구분 ② 심부름 공식으로 지시문 작성 ③ 자기 반복 업무 1개를 지시문으로 실행(강사 계정) |
| 강사 상태 | 클라우드 가입 완료, 잔액 $15, 실행 0회. 크롬 확장프로그램 제작 경험 있음(수노 대량 다운로드 확장 직접 제작) |

### 핵심 구조 결정: "지시문은 전원이 쓰고, 실행은 강사 계정으로"

- 근거: 서비스가 유료(크레딧제)라 수강생 전원 결제 불가 + 영어 사이트·자동번역 장벽 + 강사 단독 진행이라 가입 낙오자 구조 불가.
- 수강생 실습 = 워크시트에 지시문 작성 → 채팅으로 제출 → 강사가 자기 계정으로 실시간 실행 (라이브 쇼 효과).
- 마지막 슬라이드에 "직접 해보고 싶은 분" 가입·비용 안내 1장.

## 2. 심부름 공식 (강의의 등뼈)

> **어디서 + 무엇을 어떻게 + 몇 개를 + 어떤 모양으로**

| 칸 | 묻는 말 | 예시 |
|---|---|---|
| ① 어디서 | 어느 사이트? | 유튜브에서 |
| ② 무엇을 어떻게 | 뭘 검색/클릭? 어떤 순서로? | '직장인 브이로그' 검색, 조회수순 정렬 |
| ③ 몇 개를 | 어디까지 하면 끝? | 상위 5개의 제목·채널·조회수 |
| ④ 어떤 모양으로 | 결과 형태는? | 표로 정리해줘 |

- ③이 핵심 안전장치: "끝을 정해주지 않으면 끝까지 간다" — 수노 20곡 경험담과 연결.
- 빈칸 워크시트: `______에서 ______를 검색해서, ______순으로, 상위 __개의 ______를 표로 정리해줘.`

### 나쁜 예 → 공식 적용 (교재 예제)

| ❌ | 빠진 칸 | ⭕ |
|---|---|---|
| "쇼츠 트렌드 알려줘" | 전부 | "유튜브에서 '직장인 브이로그' 검색, 조회수순, 상위 5개 제목·채널·조회수 표로" |
| "청소기 싼 데 찾아줘" | ①③④ | "네이버쇼핑과 다나와에서 '무선 청소기' 검색, 인기 상품 5개씩 가격 비교표로" |
| "우리 회사 뉴스 좀" | ②③④ | "네이버 뉴스에서 '○○' 검색, 최신순으로 오늘 기사 5개 제목·링크 목록으로" |

|---|---|---|

## 4. 도입~개념 슬라이드 초안 (6장)

1. **부업, 조사가 제일 귀찮죠** — 노트: 채팅 질문 "맨날 반복하는 일 하나만"
2. **(시연/녹화 30초~1분)** — 노트: 설명 없이 지켜보게. 끝나면 "제가 방금 마우스에 손 안 댔습니다."
3. **방금 그게 Browser Use입니다** — "AI에게 눈과 손을 달아 나 대신 브라우저를 조작하게 하는 도구". 시각: 뇌+눈손+크롬
4. **대리기사라고 생각하세요** — 서핑=운전, Browser Use=대리기사. 매크로=정해진 길만 가는 버스
5. **되는 일 / 안 되는 일** — 검색·조사·비교·정리 ⭕ / 로그인·결제·보안문자 ❌. "대리기사한테 통장 안 맡기죠?" O/X 퀴즈
6. **오늘 2시간 뒤, 여러분은** — 공식 한 줄 예고

## 5. 강의에 쓸 비유·경험담 재고

- **대리기사 비유** (핵심): 확장프로그램=차에 다는 옵션(내비·블랙박스, 운전은 내가) / Browser Use=대리기사(말로 시키면 대신 운전). 한 줄 요약: "확장프로그램은 내 차를 좋게 만드는 것, Browser Use는 운전을 통째로 맡기는 것."
- **도구 선택 기준**: 똑같은 동작 반복 → 확장프로그램(빠르고 공짜, 안 틀림) / 매번 판단 필요 → Browser Use. 강사의 수노 대량 다운로드 확장이 "제가 둘 다 해봤는데요" 시연 재료.
- **수노 20곡 사건** (한계 파트 경험담): GPT에게 수노 곡 생성을 시켰더니 개수 제한이 없어 한 달치 크레딧으로 20곡 생성. → 공식 ③ "끝을 정해줘라" + "계정·크레딧 걸린 일에는 상한을 붙여라" 안전 수칙.
- **버셀 vs Browser Use 로그인**: 버셀은 코드 배포 서비스라 깃허브 로그인이 본질, Browser Use 클라우드는 일반 웹서비스(구글/이메일). 수강생 안내는 깃허브 언급 금지.
- **API 키 구분**: 설치(오픈소스) 버전만 LLM API 키 필요. 클라우드 웹 버전은 불필요(크레딧제). 대시보드의 "API 키"는 개발자용 — **화면 공유 시 노출 금지**(타인이 잔액 사용 가능).
- **확장프로그램 강의(별개 주제)**: GPT/제미나이로 코드 생성 → `chrome://extensions` 개발자 모드 → 압축해제 로드로 "내 크롬 설치"까지가 종착점. 웹스토어 배포는 $5+심사 며칠이라 수업 내 불가. 2시간에 두 주제 실습은 불가(주제당 60~70분) — 이번 강의에선 시연 5분 또는 2회차 제안.

## 6. 강사 단독 온라인 운영 수칙

- **강의 전으로 밀어내기**: 사전 안내문(크롬으로 접속·카톡 인앱 금지, 지시문 문서 링크). 강사 실행 구조라 수강생 가입 안내는 불필요해짐.
- **낙오자 프로토콜**: "채팅에 '안돼요'만 남기고 화면 보세요" → 실습 블록 끝 5분 구조 → 그래도 안 되면 녹화·자료로 강의 후 이관.
- **성공 녹화본 = 조수**: 라이브 시연이 깨지면 "이럴 때도 있다는 걸 보셨죠" 하고 녹화 전환.
- 화면 공유 중 채팅 안 보임 → 폰/두 번째 창으로 채팅, "실습 구간마다 몰아서 확인" 선언.
- 시연 리허설 최소 2회, 두 번 다 성공한 지시문만 시연 목록에.

## 7. 남은 확인 사항 (미실측)

1. **첫 실행 미완**: 대시보드 입력창에 3번 문단 1순위 지시문 복붙 → 실행 → 결과 품질·소요 시간·잔액 차감액($15 → ?) 실측. 이 차감액이 지시문 1회 비용 = 강의 예산 근거.
2. **의뢰처 확인 2건**: ① 수강생이 주로 누구인지(직장인/자영업/구직자) ② "Browser Use 실습 + 확장프로그램 시연 5분" 구성 또는 2회차 분리 중 택일.
3. **당근마켓 지시문 실측** (지역 설정 간섭 여부).
4. 무료 크레딧 $15의 출처(가입 보너스인지 결제인지) — 수강생 안내 문구에 필요.
