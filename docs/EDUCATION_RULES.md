# EDUCATION_RULES.md — 치과 의료기관 법정 의무교육 근거 (의원·병원)

`LABOR_RULES.md` 와 같은 성격의 근거 문서다. 앱의 **의무교육 점검표**가 무엇을 근거로 무엇을 보여 주는지,
그리고 **무엇을 확인하지 못했는지**를 남긴다. 다음 세션이 같은 조사를 되풀이하지 않게 하려는 것이다.

- 조사일: **2026-10-07** · 조사 대상: 직원 30인 이하 치과의원 + 병원급(규모별 차이 표시)
- 방법: 국가법령정보센터(law.go.kr) 법령 원문 API 대조 + 웹 검색. 확신도는 아래처럼 적는다.
  - **원문** — 법령 원문을 직접 대조했다
  - **미러** — 법령 본문을 옮긴 사이트(casenote 등)로 대조. 개정 반영이 늦을 수 있다
  - **2차** — 기사·협회 안내만. 앱에는 확정 문구로 쓰지 않는다
- **이 문서는 법률 자문이 아니다.** 앱은 "빠진 것을 찾는 점검표"이고 "이러면 문제없다"는 판정이 아니다.
  병원마다 다른 사정은 노무사·관할 기관에 확인한다.
- 앱 화면에는 **조문과 주기만** 쓴다. **과태료 금액은 쓰지 않는다**(법이 자주 바뀐다). 금액은 이 문서에만 둔다.

## 1. 앱이 하는 일 / 하지 않는 일

| 한다 | 하지 않는다 |
|---|---|
| 교육 종류·주기·근거 조문을 보여 준다 | 교육을 앱 안에서 진행한다(링크로 연결만) |
| 직원별 이수일·방식(외부/자체)·다음 기한을 기록한다 | 이수를 검증한다(사용자가 입력) |
| 자체교육용 교육일지·참석자 명단 서식을 만든다 | 이수증·서류 사진을 앱에 저장한다(보관 위치만 적는다) |
| 서류를 PDF 로 만들어 폰 공유 기능으로 팩스·이메일 앱에 넘긴다 | 팩스·이메일을 앱이 직접 쏜다(서버 단계) |

## 2. 모든 병원에 해당하는 교육 (규모 무관)

### 2-1. 직장 내 성희롱 예방교육 — 확신도: 원문
- **근거**: 남녀고용평등과 일·가정 양립 지원에 관한 법률 제13조(교육), 같은 법 시행령 제3조
- **주기**: 연 1회 이상. **시간 수는 규정 없음**("1시간"은 2차 자료)
- **대상**: 사업주와 근로자 모두. 5인 미만도 적용(동거 친족만 있는 사업장 제외)
- **방법**: 직원연수·조회·회의·사이버교육. 단순 게시·배포·메일은 전달 확인이 어려워 교육으로 보지 않는다
- **10인 미만이거나 모두 한 성(性)이면** 교육자료·홍보물 게시·배포로 할 수 있다(시행령 제3조제4항). 10인 이상은 불가
- **게시 의무**: 교육 내용을 근로자가 언제든 볼 수 있는 곳에 게시·비치(법 제13조제3항). 규모 예외 없음
- **기록 보관**: 교육 실시를 확인할 서류를 **3년**(법 제33조, 시행령 제19조)
- **과태료**: 미실시·게시 위반 모두 500만원 이하(법 제39조제3항)
- 자체교육 가능. 무료 공식 링크는 확인 못 함

### 2-2. 직장 내 장애인 인식개선 교육 — 확신도: 원문
- **근거**: 장애인고용촉진 및 직업재활법 제5조의2, 같은 법 시행령 제5조의2
- **주기**: 연 1회, **1시간 이상**
- **적용**: 규모 하한 없음. **상시 50명 미만**(장애인 고용의무 없는 사업주)은 고용노동부 보급 자료를 배포·게시·메일 발송하는 방식도 가능
- **기록 보관**: **3년**(법 제5조의2제3항)
- **과태료**: 300만원 이하(법 제86조제2항). 1·2·3차 100·200·300만원
- ⚠ 일부 기사의 "과태료 없음"은 원문과 다르다. 다만 게시·배포가 교육으로 인정되는 규모에서는 실제 부과 가능성이 낮아 보인다(추론)
- 링크: <https://www.able-edu.or.kr> (접속만 확인, 무료 여부 확인 못 함) · 한국장애인고용공단 <https://www.kead.or.kr>

### 2-3. 개인정보 보호교육 — 확신도: 원문(주기·시간은 규정 없음)
- **근거**: 개인정보 보호법 제28조제2항(취급자에게 정기적 교육), 시행령 제30조, 개인정보의 안전성 확보조치 기준 제4조제2항(고시)
- **주기·시간**: **정해진 횟수·시간 없음**. "정기적으로"만 있다
- **과태료**: 교육 자체를 직접 근거로 한 과태료는 확인 못 함
- 소상공인의 내부 관리계획 생략(고시 제4조제1항 단서)이 교육 의무까지 면제하는지는 원문상 불분명
- 링크: <https://edu.privacy.go.kr> (접속만 확인)

### 2-4. 퇴직연금 교육 — 확신도: 원문 · **퇴직연금을 도입한 병원만**
- **근거**: 근로자퇴직급여 보장법 제32조제2항, 시행령 제32조·제32조의2
- **주기**: 매년 1회 이상. 퇴직금 제도만 쓰면 해당 없음
- **과태료**: 1천만원 이하(법 제48조제1항). 1·2·3차 200·500·1000만원
- 링크: 확인 못 함

### 2-5. 직장 내 괴롭힘 예방교육 — 법정 의무 **아님** (원문)
- 근로기준법 제76조의2·제76조의3 에 교육 의무 조문이 없고 과태료도 없다.
  성희롱 교육에 함께 넣어 하는 것은 가능하다(해석)

## 3. 산업안전보건교육 — 규모와 "병원 여부"에 따라 갈린다 (확신도: 원문)

기사의 "50인 미만은 안 해도 된다"와 "사무직 분기 3시간"이 엇갈렸다. 원문(법·시행령·시행규칙, 2026-08-01 시행본)은 이렇다.

| 대상 | 정기·채용 시·작업내용 변경 시 교육 | 근거 |
|---|---|---|
| **상시 50명 미만 의원**(보건업, 병원 제외) | **적용 제외** | 시행령 제2조·별표 1 제3호 |
| **병원**(규모 무관) | 적용 | 같은 별표에서 병원은 제외 대상이 아님 |
| 상시 50명 이상 | 적용 | |
| 상시 5명 미만 | 위 교육은 제외되나 **특별교육(법 제29조제3항)은 남는다** | 별표 1 제6호 |

- **정기교육 시간**(시행규칙 별표 4): 사무직 **매반기 6시간** · 판매업무 직접 종사 **매반기 6시간** · 그 밖의 근로자 **매반기 12시간** · 관리감독자 연 16시간
  - "매분기 3시간"은 옛 기준으로 보인다(개정 연혁은 2차 자료)
  - 의료업 직원이 "사무직"인지 "그 밖의 근로자"인지는 원문에 명시가 없다 → 확인 못 함
- **채용 시** 8시간(일용직 1시간, 1주 이하 기간제 1시간, 1주~1개월 기간제 4시간) · **작업내용 변경 시** 2시간
- **특별교육**: 방사선 작업(별표 5)은 괄호로 **"의료 및 실험용은 제외"**. 치과 엑스선은 대상이 아닌 것으로 읽힌다. 다른 호(주사침 등)는 전수 검토하지 못했다
- **직무교육**: 안전보건관리책임자는 상시 **100명 이상**부터. 100명 미만 의원엔 대상자가 없는 것으로 읽힌다. 안전·보건관리자 선임 의무(영 별표 3·5)는 확인 못 함
- **과태료**: 정기교육 미실시 500만원 이하(법 제175조제5항), 규모별 감경(10명 미만 70%, 10~50명 미만 80%)
- **기록 보관**: 교육일지 보존기간을 정한 조문은 **찾지 못했다**. 3년 권고는 2차 자료
- **자체교육 가능**(시행규칙 제26조제3항): 강사는 관리감독자·안전보건관리책임자 등
- **⚠ 열린 질문**: 치과의원·치과병원이 법상(한국표준산업분류) **"병원"에 해당하는지** — 50인 미만 면제 여부를 가르는데 확인 못 했다.
  앱은 이 항목을 **"확인 필요"** 로 낸다(확정 문구 금지)
- 링크: <https://www.kosha.or.kr> · <https://www.moel.go.kr> (개별 무료 과정 URL은 확인 못 함)

## 5. 앱에 넣는 방식 (제안)

1. **교육 목록**은 위 표에서 **원문**으로 확인된 것을 기본으로 놓는다: 성희롱 예방 · 장애인 인식개선 · 개인정보 보호 ·
   (선택) 퇴직연금 · 방사선 안전관리 · 의료인 보수교육 · 아동학대 신고의무자 · 감염관리 직원 교육
2. **병원이 켜고 끄고 이름을 고칠 수 있다.** 의무가 아닌 것을 의무처럼 보이지 않게 한다
3. **2차 자료만 있는 것**(의료폐기물·마약류·소방·환자안전)은 "확인 필요"로 표시해 기본에서 뺀다
4. **주기를 앱이 고정하지 않는다.** 근거에 연 1회가 있는 것만 기본 주기로 두고, 방사선 보수처럼 엇갈린 건 사용자가 다음 기한을 직접 넣는다
5. **병원 규모(직원 수)** 는 이미 앱에 있는 설정(우리 병원 직원 수)을 쓴다. 규모에 따른 대체 방법(10인 미만 게시·배포 등)은 안내로만 낸다
6. 서류: 교육일지·참석자 명단 서식(자체교육용), **3년 보존**(성희롱·장애인 근거)을 안내

## 6. 확인하지 못한 것 (다음 조사 후보)
1. 치과의원·치과병원이 산업안전보건법상 "병원"인지(한국표준산업분류)
2. 의료업 직원이 정기교육의 "사무직 / 그 밖의 근로자" 중 어디인지
3. 방사선 보수교육 주기(2년/3년)
4. 감염관리 직원 교육의 시행규칙 주기·시간·과태료
