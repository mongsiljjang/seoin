# 화면 와이어프레임 요약

## 관리자 하단탭
홈 / 재고 / 근태 / 연차 / 직원
설정, 내보내기, 감사로그는 프로필 메뉴로 이동.

## 관리자 홈
- 오늘 처리할 일
- 근태 카드: 근무중, 지각, 휴가, 미퇴근
- 재고 카드: 부족, 유통기한 임박, 발주, 입고대기
- 패키지 위험: 만료 D-day, 잔액, 서비스 잔여, 담당자
- 이번달 구매액

## 직원 홈
- 오늘 근무시간
- 큰 출근/퇴근 CTA
- 내 연차 잔여
- 연차신청/근무변경
- 이번달 근태
- 팀 근무/휴가 현황

## 재고 메인
- 검색
- 전체/부족/임박 카운트
- 확인 필요 리스트
- 품목/유통기한/발주/거래처/패키지 바로가기

## 품목 상세
- 현재재고/최소재고
- -1 / -5 / 입고
- 거래처/최근단가
- 최근 재고이력

## 패키지 메인
- 총 사용가능 잔액
- 30일 이내 만료 금액
- 패키지별 D-day/잔액/서비스수량/담당자

## 패키지 상세
- 입금액/사용가능액/잔액
- 적용품목
- 서비스 상품 잔여
- 만료 대응 상태
- 패키지 사용 / 교환 / 재계약

## 근태 관리자
- 예정/출근/휴가/지각/미퇴근
- 직원별 상태
- 수정요청 큐

## 연차 승인
- 직원/날짜/유형/현재잔여/승인후잔여/사유
- 승인/반려
