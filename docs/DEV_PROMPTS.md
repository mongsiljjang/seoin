# AI 개발 프롬프트 체계

## 마스터 원칙
- 전체 앱을 한 번에 구현하지 않는다.
- 각 단계는 DB → 권한/RLS → 서버검증 → UI → 테스트 순서.
- 현재값과 거래이력 분리.
- 재고수량, 패키지잔액, 실제 현금지출을 절대 동일 값으로 취급하지 않는다.
- 중요 수정은 audit_logs.
- 삭제 대신 inactive/reversal 우선.
- 모든 주요 테이블에 hospital_id.
- 금액은 원 단위 정수형.
- 과거 근태 scheduled_start/end는 snapshot.
- 클라이언트 계산만 신뢰하지 않는다.
