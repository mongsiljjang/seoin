# 🎵 플리 곡 자동 분류기

수노에서 만든 곡을 폴더에 넣으면, 곡마다 **빠르기(BPM)·힘·밝기**를 재서
"이 곡은 몇 번 믹스에 어울린다"를 알려주고, 믹스 안의 **곡 순서**(잔잔하게
시작 → 고조 → 마무리)까지 제안합니다. 엑셀로 열리는 곡 카탈로그도 만들어 줍니다.

인터넷 연결도, 유료 API도 쓰지 않습니다. 전부 내 컴퓨터 안에서 계산합니다. **비용 0원.**

---

## 처음 한 번만: 설치 (약 5분)

1. **파이썬 설치** — https://www.python.org/downloads/ 에서 내려받아 설치.
   설치 첫 화면에서 **"Add Python to PATH" 체크박스를 꼭 켜세요.**
2. 명령창을 열고(윈도우: 시작 → `cmd` 입력) 아래 한 줄 입력:
   ```
   pip install librosa soundfile
   ```

## 쓸 때마다: 두 단계

1. 수노에서 받은 곡(mp3)을 폴더 하나에 모아둡니다. 예: `내곡들`
2. 명령창에서:
   ```
   python classify.py 내곡들
   ```
   (맥이라면 `python3 classify.py 내곡들`)

그러면:
- 화면에 곡별 분석 결과와 **테마 제안**(차선 후보 포함)이 나오고
- 테마별로 묶인 **곡 순서 제안**이 나오고
- `내곡들/카탈로그.csv` 파일이 생깁니다 (엑셀에서 바로 열림 — 업로드 상태 관리용)

## 결과 예시

```
[1/3] 새벽에만든곡.mp3
    빠르기 72.0 BPM · 힘 0.06 · 밝기 1240 Hz
    → 2번 「새벽 감성」 (어울림 93%)   차선: 6번 「잠들기 전」 (81%)

■ 2번 「새벽 감성」 — 10곡, 약 34:20
   1. 조용한인트로곡.mp3  (68 BPM, 힘 0.04)
   2. ...
```

## 테마(믹스 기준)를 바꾸고 싶으면

`themes.json` 파일을 메모장으로 열어 고치면 됩니다. 테마 8개의
이름·BPM 범위·힘·밝기 기준이 들어 있고, 파일 안에 각 숫자의 뜻이 적혀 있어요.
채널 방향이 정해지면 이 파일을 그 컨셉에 맞게 다시 짜면 됩니다.

## 팁

- 파일명 앞에 `03-`처럼 테마 번호를 미리 붙여두는 습관을 들이면,
  분류기 제안과 비교해서 "의도와 다르게 나온 곡"을 골라내기 좋습니다.
- 어울림 %가 두 테마 모두 낮게 나오는 곡은 어느 믹스에도 안 어울린다는
  뜻이니 "보관함"으로 빼두세요. 나중에 새 테마를 만들 때 재료가 됩니다.
- 아주 느린 곡은 BPM이 실제의 두 배로 잡히기도 합니다(음악 분석의 흔한
  한계). 스크립트가 어느 정도 보정하지만, 이상하면 귀를 믿으세요.
